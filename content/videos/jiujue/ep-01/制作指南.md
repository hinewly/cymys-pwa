# 第一式《识己》制作包

- last_updated: 2026-10-18
- 目标成片：竖屏 9:16（1080×1920），约 60 秒
- 制作工具：即梦AI（人物形象 + 对口型）+ 剪映（配音、字幕、合成）

## 本包内容

| 文件 | 用途 |
|---|---|
| `口播-识己.txt` | 配音文本，直接粘进剪映"文本朗读" |
| `字幕-识己.srt` | 参考时间轴字幕（剪映也可用"识别字幕"自动生成，以自动为准） |
| `assets/片头卡.png` | 开场 3 秒标题卡 |
| `assets/底图-水墨山水.png` | 正文底图（无人物版，用于口播过场） |
| `assets/片尾卡-识己.png` | 结尾 3 秒片尾卡 |
| （即梦生成）老掌门人物视频 | 正文主体 |

## 第一步：即梦生成老掌门形象

打开即梦AI（jimeng.jianying.com），用"图片生成"，粘贴以下提示词：

> 中国水墨画风格，一位仙风道骨的老年武学宗师，形似张三丰：银白长须，白色道袍，宽袍大袖，面容清癯慈和，眼神深邃平静。半身正面像，双手交叠于身前，站姿端正，嘴唇自然闭合。背景是留白的水墨远山与云雾，宣纸质感，笔触苍劲，古朴大气。竖版构图。

要点：
- 生成 2~4 张，挑一张**表情最沉稳、五官清晰**的定为"全系列统一形象"（之后 8 集都用这张做基准，保证人物一致）；
- 建议保存这张图为"形象基准图"，以后生成其他集的姿态时，用即梦的"参考图/角色一致性"功能带上它。

## 第二步：即梦生成"开口讲述"视频

1. 即梦 → "视频生成 / 对口型"功能；
2. 上传老掌门形象图 + 第一式配音音频（先在剪映里用"文本朗读"把 `口播-识己.txt` 转成音频导出）；
3. 生成后人物嘴型随台词开合，衣袖有轻微飘动——即梦免费额度足够 9 集；
4. 如果口型断句不自然，把口播拆成 2~3 段分别生成再拼接。

## 第三步：剪映合成

1. 新建 9:16 项目；
2. 轨道顺序：
   - 片头卡（3 秒，可加缓慢放大动效）
   - 老掌门讲述视频（主体，背景若带底图更好，也可抠像叠在 `底图-水墨山水.png` 上）
   - 片尾卡（3 秒）
3. 音频：讲述音频铺满正文；
4. 字幕：导入 `字幕-识己.srt` 或用"识别字幕"，重点句（「麻将之道，第一在人」「知己者，行远」）手动放大加粗；
5. 背景音乐：选古琴/箫类曲目，音量压到 15% 左右；
6. 导出 1080×1920，30fps。
