# 《雀行十三绝》完整脚本与分镜

- last_updated: 2026-10-17
- 说明：每集口播 180~220 字，正常语速约 50~58 秒。竖屏 9:16。
- 视觉总原则：**立身之境无牌，得法之境牌进场，观势之境牌成河，天成之境牌退场。** 道在前，术在后，最后归于无。

---

# 第一境 · 立身（式 1~3）

> 视觉基调：水墨山水、武侠剪影、书法字卡。全境无麻将牌。

## 第一式 · 识己

**口播全文（约 55 秒）：**

江湖上有个问题：郭靖和杨过，谁是高手？郭靖天资鲁钝，一套降龙十八掌，练了一万遍；杨过聪明绝顶，一把玄铁重剑，走的是险路。可最后，他们都成了宗师。打牌也一样。有人对数字敏感，一眼算清剩余张数；有人对人心敏感，一坐上桌就知道谁在诈。可从没有一种打法，适合所有人。认清自己是哪块料，比学会一百种技巧更要紧。这，是雀行的第一式：识己。问自己一句——你，是郭靖，还是杨过？

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 水墨雾气渐开，山门剪影 | 片头字卡：雀行十三绝 |
| 6-14s | 郭靖式憨厚剪影反复练拳 / 杨过式剑客剪影独行 | 「郭靖和杨过，谁是高手？」 |
| 14-24s | 两个剪影各自登顶，山顶相望 | 「他们都成了宗师」 |
| 24-38s | 水墨长卷展开：一张桌，两种坐姿 | 「从没有一种打法，适合所有人」 |
| 38-50s | 卷轴收起，只留一个问号化作书法大字「识己」 | 「认清自己，比一百种技巧更要紧」 |
| 50-58s | 定格：黑底书法「雀行十三绝·第一式 识己」 | 系列片尾卡 |

## 第二式 · 立本

**口播全文（约 55 秒）：**

扫地僧在藏经阁扫了几十年地，扫出了天下第一。为什么？笨功夫，才是真功夫。打牌的人总想找绝招，可高手都在做最无聊的事：记牌、算张、复盘。一万个几乎同样的动作，重复到不用想。基础不牢的人，赢牌靠运气；基础扎实的人，输牌也输得明白。真正的捷径，从来都是那条看起来最慢的路。第二式：立本。把根扎深，风来了，你才站得住。

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 藏经阁剪影，一僧人扫地，尘光斜照 | 片头字卡 |
| 6-16s | 扫帚划过地面的特写，慢镜，重复 | 「笨功夫，才是真功夫」 |
| 16-26s | 水墨对比：左边火花四溅的"绝招"，右边静水深流的"重复" | 「高手都在做最无聊的事」 |
| 26-38s | 一棵树的根在地下蔓延（水墨动画） | 「基础不牢，赢牌靠运气」 |
| 38-50s | 风吹过，树不动 | 「真正的捷径，看起来最慢」 |
| 50-58s | 定格：「第二式 立本」 | 系列片尾卡 |

## 第三式 · 知守

**口播全文（约 52 秒）：**

学武先学挨打，练牌先学守规矩。规矩不是捆住你的绳，是托住你的底。什么牌能碰，什么牌该舍，什么局该退——守住这些的人，才配谈"破"。江湖里倒下最快的，往往不是最弱的，而是最不安分的。牌品即人品。桌上守不住规矩的人，桌子之外，也难守本心。第三式：知守。守得住，才有资格破。

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 一张麻将牌的剪影立在画面中央（全系列第一张牌出现，仅剪影） | 片头字卡 |
| 6-16s | 剪影牌四周升起细线，如弓弦拉满 | 「规矩不是绳，是底」 |
| 16-26s | 水墨武侠：一个毛躁剑客闯阵被击退 | 「倒下最快的，是最不安分的」 |
| 26-38s | 剪影牌稳稳立住，光影如印章落下 | 「牌品即人品」 |
| 38-52s | 定格：「第三式 知守」 | 「守得住，才有资格破」 |

# 第二境 · 得法（式 4~7）

> 视觉基调：麻将牌开始进场，但只给局部——手、几张牌、牌桌一角。

## 第四式 · 通变

**口播全文（约 55 秒）：**

招是死的，人是活的。郭靖把降龙十八掌练到极致，才明白：同一招亢龙有悔，对不同的对手，出手的方式完全不同。牌也是。书上教你拆搭留对，可牌桌从没有一样的牌局。上一把的经验，救不了这一把的你。死记招式的人，是匠；看菜下饭的人，才是高手。第四式：通变。招要熟，更要活。

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 三张麻将牌（实拍/特写）从暗处亮起 | 片头字卡（牌第一次以实面目出现） |
| 6-16s | 水墨：郭靖出掌，掌风分出三种走向 | 「同一招，三种出手」 |
| 16-26s | 三张牌排列，随后其中一张被抽走、重排 | 「牌桌从没有一样的牌局」 |
| 26-38s | 快切：同一张牌在不同牌局里被舍/被留 | 「上一把的经验，救不了这一把」 |
| 38-50s | 牌阵如活棋般流转 | 「招要熟，更要活」 |
| 50-58s | 定格：「第四式 通变」 | 系列片尾卡 |

## 第五式 · 察人

**口播全文（约 55 秒）：**

高手看牌，先看人。对手碰牌时手抖不抖，舍牌时犹豫不犹豫，赢家输家脸上的松弛与紧绷——牌会骗人，人不会。你读牌算的是概率，读人算的是心。同样一手牌，对急躁的人快打，对沉稳的人慢磨。牌桌上没有两只一样的手，也没有两个一样的对手。第五式：察人。看牌是术，看人是道。

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 牌桌一角，四只手入画 | 片头字卡 |
| 6-16s | 特写：一只手碰牌时微微一抖（慢镜） | 「牌会骗人，人不会」 |
| 16-26s | 特写：赢家松弛的手 vs 输家紧绷的手 | 「读牌算概率，读人算心」 |
| 26-38s | 视角切换：镜头从"看牌"缓缓摇到"看人" | 「看牌是术，看人是道」 |
| 38-50s | 四只手同时伸向牌河，定格 | 「没有两个一样的对手」 |
| 50-58s | 定格：「第五式 察人」 | 系列片尾卡 |

## 第六式 · 舍得

**口播全文（约 52 秒）：**

每一次舍牌，都是一次选择。你舍掉的那张，其实是你真正选定的路。手里抓着一对好搭子，谁都想留；可留恋太多，路就走窄了。会舍的人不怕丢——他知道，舍掉杂念，才守得住主攻。人生也一样：你不敢舍的，最后都在拖住你。第六式：舍得。舍，不是失去，是选定了方向。

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 一只手捏着一张牌，悬而未决 | 片头字卡 |
| 6-16s | 手中多张牌依次亮起又熄灭，只留一张 | 「留恋太多，路就走窄了」 |
| 16-26s | 那张牌被缓缓推向牌桌中央，定格 | 「你舍掉的，是你选定的路」 |
| 26-38s | 水墨：落子无悔的印章感 | 「舍，不是失去，是选定方向」 |
| 38-52s | 定格：「第六式 舍得」 | 系列片尾卡 |

## 第七式 · 借势

**口播全文（约 55 秒）：**

顺风别浪，逆风别急。牌桌上的势，像风：看不见，摸不着，但高手身上有感觉。势顺时，要快，要压，要乘胜；势背时，要慢，要守，要熬。逆风硬拼的人，是把本钱交给了运气。武侠里借力打力，牌桌上借势打势。第七式：借势。风不常有，会等风的人，才配得起风。

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 水墨风起，吹动牌河里的一张牌 | 片头字卡 |
| 6-16s | 势顺：牌如流水连出（快镜） | 「势顺时，要快，要压」 |
| 16-26s | 势背：牌河凝滞，一手牌收住不动（慢镜） | 「势背时，要慢，要熬」 |
| 26-38s | 水墨武侠：借力打力的过招剪影 | 「逆风硬拼，是把本钱交给运气」 |
| 38-50s | 一个人立在山口，等风来，风起 | 「会等风的人，才配得起风」 |
| 50-58s | 定格：「第七式 借势」 | 系列片尾卡 |

# 第三境 · 观势（式 8~10）

> 视觉基调：牌河俯拍、牌浪动效、慢镜与模糊。牌不再是一张一张，而是一片一片。

## 第八式 · 观势

**口播全文（约 52 秒）：**

打牌打得越久，越会发现：牌是活的。有一股浪在牌桌上涌动，谁碰到谁胡，什么牌络绎不绝——这就是势。低手只看自己手里的十三张，高手看的是整张桌子的流向。逆着浪打，会游的也呛水；顺着浪走，不划水也能走远。第八式：观势。抬头看浪，比低头数牌，重要得多。

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 俯拍整张牌桌，牌河如水波纹 | 片头字卡 |
| 6-16s | 牌河动效：某一种牌接连出现，浪起 | 「牌是活的」 |
| 16-26s | 分屏：左边只盯手牌的眼睛，右边俯瞰全桌的视角 | 「低手看十三张，高手看流向」 |
| 26-38s | 水墨浪涛与牌河叠化 | 「逆浪呛水，顺浪走远」 |
| 38-52s | 定格：「第八式 观势」 | 「抬头看浪，比低头数牌重要」 |

## 第九式 · 藏锋

**口播全文（约 52 秒）：**

好牌不显，险牌不露。真正的高手抓到天牌，脸上和抓到烂牌没有任何区别。你一喜，对手就防；你一急，对手就退。剑客藏锋，是为了出鞘那一瞬；牌客藏锋，是为了听牌那一张。桌上的表情，就是你的第二手牌。第九式：藏锋。锋芒收得住的人，才谈得上锋芒。

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 一只手摸牌，牌面朝下，看不见 | 片头字卡 |
| 6-16s | 特写：抓到牌后的脸——毫无波澜 | 「抓到天牌，和抓到烂牌没有区别」 |
| 16-26s | 水墨：剑在鞘中，鞘上落雪 | 「剑客藏锋，为了出鞘一瞬」 |
| 26-38s | 手把牌轻轻扣下，扣在牌墙里 | 「牌客藏锋，为了听牌那一张」 |
| 38-52s | 定格：「第九式 藏锋」 | 「你的表情，是你的第二手牌」 |

## 第十式 · 忘招

**口播全文（约 55 秒）：**

练到深处，口诀会消失。你不再想"该拆哪一搭"，手已经先做出了选择；你不再数"还剩几张"，心里自然有数。这不是玄学，是一万遍重复之后的本能。独孤求败晚年用木剑，甚至不用剑——不是因为忘了剑，而是剑已经长在了身上。第十式：忘招。忘了招的人，才真正拥有了招。

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 牌面虚化，只余手部剪影 | 片头字卡 |
| 6-16s | 手自动舍牌，快到不像思考（慢镜呈现"不经意"） | 「手已经先做出了选择」 |
| 16-26s | 水墨：独孤求败的木剑插入海边沙土 | 「剑已经长在了身上」 |
| 26-38s | 虚焦牌面渐渐重新清晰，又缓缓淡去 | 「一万遍重复之后的本能」 |
| 38-50s | 空桌，一张牌都没有 | 「忘了招的人，才拥有招」 |
| 50-58s | 定格：「第十式 忘招」 | 系列片尾卡 |

# 第四境 · 天成（式 11~13）

> 视觉基调：回到水墨留白，极简。牌基本退场，只在第 12 式以"传说"的方式惊鸿一瞥。

## 第十一式 · 观心

**口播全文（约 52 秒）：**

牌打到最高处，比的不是牌，是心。连输八把面不改色，大赢一把不动声色——这不是装出来的定力，是修出来的心性。牌桌是最好的镜子：你贪，牌看得见；你慌，牌也看得见。急着翻本的人，往往输得更快。第十一式：观心。管住手之前，先管住心。

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 水墨留白，一滴墨落入水中 | 片头字卡 |
| 6-16s | 一个人的剪影在桌前，桌对面空无一人（对手是他自己） | 「比的不是牌，是心」 |
| 16-26s | 墨水在水里散开成心形/乱流，随呼吸缓下来 | 「牌桌是最好的镜子」 |
| 26-38s | 墨色沉淀，水变清 | 「管住手之前，先管住心」 |
| 38-52s | 定格：「第十一式 观心」 | 系列片尾卡 |

## 第十二式 · 鬼神

**口播全文（约 58 秒）：**

日本麻将的传说里，有一个境界叫"鬼神"：看穿牌山，读破手牌，仿佛明牌而战。有人穷尽一生也摸不到边。它靠的不是千术，是天分、万局、和一点点"悟"——就像少林寺的扫地僧，你根本看不出他会武功。这一式，我不教你到达它，我只告诉你：它存在。第十二式：鬼神。知道山有多高，才知道自己还在山脚——这不丢人，这是开始。

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 全黑，一盏烛火亮起（全系列最暗的一集） | 片头字卡（低沉配乐） |
| 6-16s | 传说感画面：牌山剪影，所有牌面隐隐透光（"看穿牌山"） | 「仿佛明牌而战」 |
| 16-26s | 扫地僧剪影，扫帚划过，地面上现出牌局的纹路 | 「你根本看不出他会武功」 |
| 26-38s | 烛火熄灭又亮，一张牌的背面朝上，纹丝不动 | 「它存在」 |
| 38-50s | 水墨：仰望高山，山巅一点灯光 | 「知道山有多高，才知道自己在山脚」 |
| 50-58s | 定格：「第十二式 鬼神」（金色字） | 系列片尾卡 |

## 第十三式 · 归真（收式）

**口播全文（约 58 秒）：**

十三式讲完了。你可能发现：从头到尾，我没教你一张怎么打。因为道这个东西，说不尽，也学不完——我只能指给你看，路得你自己走。散场之后，牌会散，局会散，你带走的，是这十三式在你心里留下的那一丁点东西。雀行十三绝，最后一式：归真。返璞归真——牌桌如江湖，出走半生，归来仍是初心。

**分镜：**

| 时间 | 画面 | 字幕/重点 |
|---|---|---|
| 0-6s | 十二个式名如卷轴依次闪过，最后归于一张白纸 | 片头字卡 |
| 6-16s | 牌桌撤去，桌面上只留一道浅浅的痕 | 「我没教你一张怎么打」 |
| 16-26s | 白纸上落下一滴墨，缓缓晕成「归真」二字 | 「路得你自己走」 |
| 26-38s | 江湖远景：一个人背对镜头走远（全系列第一个全景人像） | 「出走半生，归来仍是初心」 |
| 38-50s | 白纸上浮现全部十三式名，如星图 | 「你带走的，是心里那一丁点东西」 |
| 50-58s | 定格：「雀行十三绝 · 完」 | 引导：到 app 里的拆搭练习，走第一步 |
