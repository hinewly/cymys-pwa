# 牌经课堂内容源

状态：v0.5.0 已上线 10 课。

初步选题：

1. 川麻数字含义：边张、尖张、肩张、中张。
2. 定缺流程：不是丢最差门，而是留最有结构的一门。
3. 5 搭牌原理：让手牌向 4 副成牌加 1 对将。
4. 拆搭顺序：什么时候拆搭子、什么时候拆对子。
5. 听牌效率：4 张与 7 张牌的常见听型。
6. 做大牌条件：起手优势、上牌顺利、缺门优势。
7. 血战节奏：能胡先胡，还是要等大牌。
8. 防守思路：看上家、防下家、盯对家。

要求：

- 每篇 300~800 字，避免整页大段文字。
- 每篇配 1 个牌面示例或流程图。
- 不直接复制扫描书原文，尤其是《风哥麻将书》。
