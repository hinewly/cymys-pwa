# 《识己》系列视频脚本规划（初稿）

- 创建：2026-11-04
- 状态：规划稿，等用户审改
- 每支 45~60 秒，画面以真实牌型图为主，老掌门只在开场/收尾露面
- 制作流程沿用《雀行九绝》第一式经验：即梦生图 + 剪映对口型/配音 + 字幕

## 通用结构（品1~4）

1. 开场（5s）：老掌门一句人设引入（如"你是黄蓉，还是郭靖？"）
2. 亮牌（5s）：全屏牌型图
3. 提问停顿（5s）：字幕提问 + 3 秒静默
4. 拆解（20~25s）：口播文章正文 + 牌型拆解两三句
5. 落点收尾（5~10s）：一句道的落点 → 片尾卡「识己 · 第X品」

## 五支脚本概要

### V0 宣言《没有必胜》
- 画面：老掌门背影，牌桌远景，题字「没有必胜」
- 口播：宣言篇全文（66 字）
- 备注：这支没有牌型图，纯立场的片子，适合首发试水+私域转发

### V1 第一品·敏于算
- 牌型图：13 张手牌，含「3万4万」「1万9万」
- 提问：先拆哪一搭？
- 拆解：3万4万两面，接 2、5；1万9万一头死，只等 2 或 8（口头简化为"1万只等一头"）。位置不同，价值便不同。
- 落点：敏算是术，练而可得。

### V2 第二品·明于察
- 画面：牌池图（河内两张5筒）+ 一手含 5 筒的手牌
- 提问：此刻打 5 筒，安全吗？
- 拆解：上家连打两张 5 筒，他多半不要筒子——但"多半"不是"一定"。读人，算的是人心，不是铁律。
- 落点：概率有穷，人心无底。

### V3 第三品·定于心
- 画面：一手单钓窄听 + 牌池别家连出三次生张
- 提问：贪不贪大？
- 拆解：别家进度快、自己听牌窄，先胡先拿。守住该拿的，比做大梦强。
- 落点：定心，是知道自己此刻该要什么。

### V4 第四品·万中无一
- 画面：整局四家牌池全景图（不亮手牌）
- 提问：现在谁的牌最好？
- 拆解：答案不在任何一家手牌里，在整张桌上。谁连庄、河里走了什么、谁的手快了，势有迹可循。
- 落点：大巧不工，悟而通之。

## 发布顺序建议

V0（宣言）→ V1 → V2 → V3 → V4，每支间隔 2~3 天；图文与视频同步发。
