# 牌谱图鉴内容源

目标：把散落在 XMind、Word、截图里的经典牌型，整理成结构化的牌谱卡片。

第一批清单见 [第一批清单.md](./第一批清单.md)。

每条牌谱建议字段：

```json
{
  "id": "321",
  "name": "321 牌型",
  "category": "经典好搭",
  "tags": ["进张宽", "一上听"],
  "tiles": ["w3", "w2", "w1"],
  "summary": "简短说明它为什么是好牌型。",
  "points": ["可以上哪些牌", "实战取舍", "常见错误"],
  "source": ["麻将常见牌型2025.xmind", "经典牌型（常见错误）docx"]
}
```

注意：

- `tiles` 使用现有站点的牌图编码：`w1-w9` 万、`t1-t9` 筒、`l1-l9` 条。
- 每张截图必须先定名、写说明，再考虑上线。
- AI 或资料里的牌理要先校验，不直接照搬。
