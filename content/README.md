# cymys 内容源目录

这个目录存放“川麻茶馆”的**整理后内容源**，不是原始素材库。

原则：

1. `/Users/zoujiean/麻将` 是原始素材区，保持不动。
2. 这里只放已经筛选、定名、适合进入 PWA 的内容源。
3. 大图必须先压缩成 WebP/JPG，再进入 `public/assets/content/`。
4. 站点运行数据继续放在 `public/js/data/`，后续可由这里的 JSON/Markdown 生成。
5. 带版权水印或来源不明的整书、整文档，不直接上传；只提炼思路后重写。

## 目录规划

```text
content/
├── paipu/      牌谱·牌型图鉴

└── videos/     书场·视频讲堂
```
