# 设计决策记录

> 按时间顺序记录关键决策及其理由。新决策追加在文末。

## 2026-09-30 · 产品定位

**决策**：微信小程序整体迁移为 PWA，脱离微信生态（云函数、审核、收费），全免费栈。

**理由**：微信小程序发布限制多、收费项杂；产品定价低，PWA 的"防君子"安全级别足够。用户对 PWA 部署已有 vocab-pwa 项目经验。

## 2026-09-30 · 技术栈

**决策**：纯 HTML/CSS/vanilla JS，无框架无构建，对齐 vocab-pwa 模式。

**理由**：9 个页面规模用不上框架；无构建步骤便于持续修改；两条发布线（GitHub Actions / Cloudflare Worker）都是纯静态托管。

## 2026-09-30 · 激活码后端

**决策**：克隆 vocab 的 daobox-api 为独立 cymys-api Worker + 独立 D1 库，不共享代码实例。

**理由**：不动正在运营的 vocab 线上系统，零回归风险；成本为零。**尚未实施**。

## 2026-10-01 · 答题交互

**决策**：
- 选项红框为单选语义（只标最新错选，换选即移走）
- 上一题/下一题导航栏替代"跳过"；已完成的题回看进入复习模式（高亮正确答案+解析）
- 导航用 hash 参数直达（#/question/basic/7），越界钳制

**理由**：用户实测反馈"跳过"语义混乱、"下一题"重复；标准单选+前后翻页是最不会错的模型。

## 2026-10-01 · 视觉语言（v0.2.0 基准）

**决策**：整套视觉围绕"麻将馆"材质体系：
- 选项牌：象牙白渐变底 + mix-blend-mode: multiply（消除白底 JPG 的死白块）+ 立体投影 + 悬停浮起
- 手牌区：深绿呢面（径向渐变+内阴影），象牙白牌摆在"桌上"
- 结果卡：暖色材质，答对淡绿/答错淡红
- 导航：墨绿渐变；手机底部 3 tab，iPad/桌面顶部品牌条（底栏在 iPad 上留大空白，弃用）
- 图标：统一 1.8 描边内联 SVG，弃用 emoji

**理由**：素材是白底 JPG，直接贴显 low；用混合模式让牌面"印"在材质上。绿呢+象牙+墨绿+金构成统一色彩语言。多次迭代（v0.1.4~v0.2.1）由用户截图反馈驱动，"一屏呈现"是硬性要求。

## 2026-10-01 · 产品架构（v0.3.0 茶馆版）

**决策**：产品定位从"拆搭练习工具"升级为"川麻茶馆"文化平台。五个模块：

| 模块 | 路由 | 数据文件 | 状态 |
|------|------|---------|------|
| 茶馆（hub） | #/home | — | ✅ |
| 拆搭练习 | #/practice | questions.csv.js | ✅ 72题 |
| 牌经（牌理课堂） | #/paijing | paijing.js | 🔶 3课示例 |
| 牌谱（牌型图鉴） | #/paipu | paipu.js | 🔶 4个示例 |
| 书场（视频讲堂） | #/shuchang | videos.js | 🔶 占位 |
| 行话（川麻词典） | #/hanghua | hanghua.js | 🔶 10条 |

**理由**：竞品全是"题库刷题"工具；川麻将文化（血战规则、定缺、行话、茶馆叙事）是独有差异化。练习只是其中一部分（用户明确表示）。内容与代码分离（window.XXX 数据文件），填内容不改代码。

**导航**：手机底栏 3 tab（茶馆/拆搭/我的）；iPad 顶栏 7 项全模块。模块入口收敛在茶馆 hub 首页（今日一题 + 场子卡 + 今日行话）。

## 2026-10-01 · 部署

**决策**：Cloudflare Worker 静态托管为主站（cymys.daobox.app，国内访问快），GitHub Pages 为备用线。子域名可随时改 wrangler.toml。

**发布流程**：改 public/ → 递增 CACHE_VERSION → commit → push GitHub（Pages 自动）→ `cd worker && npx wrangler deploy`（Cloudflare）。
