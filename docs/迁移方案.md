## 原项目盘点

| 项 | 内容 |
|----|------|
| 页面 | 9 个：splash / index / home / question / sp / rclx / grzx / activate / other，约 7300 行 |
| 题库 | 72 题，CSV 内嵌（data/questions_csv.js），CSV 为唯一数据源，build.py 校验 |
| 资源 | 麻将牌 27 张 JPG（416K）+ 背景音乐 120K + 图片素材 |
| 后端 | 微信云函数 ×3：verifyCode / checkStatus / manageCode（注册码激活） |
| 认证 | openid 绑定注册码，lifetime / yearly 两种，免费 15 题额度 |
| API 依赖 | wx.getStorageSync / navigateTo / createInnerAudioContext / cloud.callFunction |

## 迁移对照表

| 小程序 | PWA 方案 |
|--------|----------|
| Page() + WXML/WXSS | Web 组件（9 页 → 9 视图，SPA 路由） |
| wx.getStorageSync | localStorage |
| wx.navigateTo | history.pushState |
| wx.createInnerAudioContext | HTML5 Audio |
| wx.cloud.callFunction | fetch → Cloudflare Worker API |
| openid | localStorage 随机设备 ID |
| 本地资源路径 | 同路径 + Service Worker 缓存 |

策略：写 wx 兼容 shim（约 200 行），utils/ 层和答题逻辑（720 行）基本不动，只改页面壳。

## 激活码体系（克隆 vocab-pwa 的 daobox-api）

- 独立 Worker：cymys-api + 独立 D1 库 cymys-db（不动 vocab 线上系统）
- 激活码 6 位数字 + 设备软绑定（3 台）+ 输错冷却 + 管理台，全部现成
- 域名：用户 Cloudflare 账号下的子域（如 cymys.daobox.app，名字待定）

## 免费资源策略

- 托管：Cloudflare Worker 静态托管（倾向）或 GitHub Pages（备用）
- 视频（未来）：B站内嵌（零成本零维护，国内快）或 Cloudflare R2（10GB 存储+流量免费）
- 不用微信云函数、不用任何收费服务

## 风险与已知限制

1. PWA 在微信内置浏览器里可用但不能安装/离线，完整体验需引导用户 Safari 打开→添加主屏
2. 前端代码可被 F12 查看，题库若打包在前端则防君子级别（与小程序现状相当）；
   如需加强可升级为"激活后 Worker 按需返回题库"（待用户确认）
3. 推广靠发链接/二维码/B站引流，无微信社交裂变
