# 内容填写指南

> 所有内容都在 `public/js/data/` 下的数据文件里，改完递增 CACHE_VERSION 发布即可。页面代码不用动。

## 1. 牌型图鉴 — `paipu.js`

```js
{
  id: 'qingyise',        // 唯一英文 id
  name: '清一色',         // 牌型名
  fan: '2番',            // 番数（血战规则，写你认的算法）
  desc: '全部由同一种花色组成……',  // 一段打法说明
  tiles: ['w1','w1','w2','w3',...],  // 牌名数组：w万 t筒 l条 + 数字，会自动渲染成牌面
  tags: ['清一色', '进阶'],           // 可选：标签
  points: ['要点一', '要点二'],       // 可选：要点列表
  note: '说明性备注',                 // 可选：结构牌型示例备注
}
```

- tiles 会按花色自动分排显示，直接照胡牌牌型罗列即可
- 番种和“结构牌型”可以混排。结构条目把 `fan` 写成 `结构`，用于讲牌效率，不一定是完整胡牌牌型。

## 2. 行话词典 — `hanghua.js`

```js
{ term: '定缺', pinyin: 'dìng quē', meaning: '解释文字', }
```

- meaning 一段话讲清楚，有典故/例句就写进去
- 首页"今日行话"每天自动从全部词条里轮一个，词条越多越有味道

## 3. 牌经课堂 — `paijing.js`

```js
{
  id: 'l04', no: 4,           // no = 课号（连续）
  title: '课标题',
  digest: '列表页的一句话摘要',
  paragraphs: ['第一段', '第二段', ...],  // 每个元素一段
}
```

## 4. 视频 — `videos.js`

```js
{ id: 'v03', title: '标题', duration: '12:30', status: 'ready', desc: '简介', url: 'B站链接' }
```

- status: 'pending' 显示"筹备中"，'ready' 显示时长
- url 字段填 B站分享链接后，我再接播放页（下一步加 iframe 内嵌）

## 5. 练习题库 — `questions_csv.js`

- CSV 格式（id,title,desc,card1-14,opt1-4,correct,explanation,diff,category）
- 可用原小程序的 tools/question_editor.html 可视化编辑器生成，产物粘进此文件
- 注意：id 用 J 开头（基础）/ Y 开头（易错）；correct 是 1-based（第几个选项）

## 发布

改完任意文件 → `public/sw.js` 递增 CACHE_VERSION → commit → push → 说一声"发布"（wrangler 部署 Cloudflare）。
